## What carries between sections

Sections are not independent. The objective pair (1) decides the pillar functions (3); the pillar functions
decide which surface each format belongs to (4); the surfaces decide how the single idea is expressed (5) and
how the concepts are specified (6); the hero campaign (7) is the cadence's anchor; the community mechanisms
(8) provide the material the calendar (10) publishes; the creator filters (9) inherit the platform roles; and
the measurement framework (11) tracks each objective separately so a slow channel cannot be mistaken for a
failing one.

## The deliberately quiet choices

- **Quiet days are scheduled**, not left blank.
- **The creator strategy names filters before names**, so substitution is safe.
- **The measurement framework includes a stop signal**, so it can fail.
- **The refusal list is printed in the deck**, because refusals carry more differentiation than promises.
